# 호환성

[English](compatibility.md)

SimpleLift 0.3.3-SNAPSHOT은 하나의 Java 8 바이트코드 JAR로 Minecraft 1.13부터 26.3까지를 지원 대상으로 합니다.

구현은 Spigot 1.13.2 API와 작은 호환 계층을 사용합니다. NMS나 마인크래프트 구현 클래스는 사용하지 않습니다. 모든 중간 버전을 실행한 것은 아닙니다.

## 0.3.3-SNAPSHOT 검증

| 대상 | JVM 또는 빌드 조건 | 결과 |
|---|---|---|
| Spigot API `1.13.2-R0.1-SNAPSHOT` | JDK 21, `--release 8` | 클린 빌드와 JUnit 47/47 |
| Paper API `26.3.build.218-stable` | JDK 25, `--release 8` | 클린 교차 컴파일과 JUnit 47/47 |
| Paper `26.3`, 빌드 157 | Java 25.0.4.1 | 기존 0.3.3-26.3-beta.2 JAR 정상 활성화 |

기존 26.3 JAR의 실행 클래스와 리소스는 게시된 0.3.3-SNAPSHOT과 같으며,
차이는 `plugin.yml`과 매니페스트의 버전 메타데이터뿐입니다.
26.3 런타임 기록은 시작만 확인한 것입니다. 이 릴리스의 전체 운행 시나리오와
클라이언트 청음 확인은 아직 반복하지 않았습니다.

## 0.3.0-SNAPSHOT 검증 결과

| 대상 | JVM 또는 빌드 조건 | 결과 |
|---|---|---|
| Spigot API `1.13.2-R0.1-SNAPSHOT` | JDK 21, `--release 8` | clean build와 JUnit 19/19 |
| Paper API `26.2.build.112-stable` | JDK 25, `--release 8` | 교차 컴파일과 JUnit 19/19 |
| Paper `1.13.2`, build 657 | Temurin 11.0.32 | 런타임 시나리오 38/38 |
| Paper `1.16.5`, build 794 | Temurin 17.0.17, Paper 버전 검사 우회 | 런타임 시나리오 38/38 |
| Paper `1.20.6`, build 151 | Temurin 21.0.9 | 런타임 시나리오 38/38 |
| Paper `1.21.8`, build 60 | Temurin 21.0.9 | 런타임 시나리오 38/38 |
| Paper `26.2`, build 112 | Temurin 25.0.4 | 런타임 시나리오 38/38 |

Paper 1.16.5는 더 오래된 Java 버전을 공식 지원합니다. 격리 시험에서는 `-DPaper.IgnoreJavaVersion=true`를 사용했습니다. 운영 서버는 사용하는 Paper 버전의 Java 요구 사항을 따라야 합니다.

## 다중 사용자

다음 상황을 런타임 시나리오로 검증했습니다.

- 같은 층의 여러 사용자가 함께 이동합니다.
- 목적지에서 기다리는 사용자는 임시 바닥 제거 중 보호됩니다.
- 이동 경로 밖의 사용자는 운행에 포함되지 않습니다.
- 운행 중인 승강로의 다른 호출은 종료 전까지 `busy`를 반환합니다.
- 정상 종료와 연속 운행 후 물리 상태와 임시 바닥이 복구됩니다.
- 표지판 선택 세션은 표지판별로 독립적이며 한 표지판에는 한 사용자만 접근합니다.
- 첫 실행에서 기존 LiftReloaded 설정을 가져올 수 있습니다.

## 높이와 부하

Paper 26.2에서 7 × 7 단면, Y=-60부터 Y=316까지 95개 층을 시험했습니다. 이동 거리는 376블록입니다.

- 고층 시나리오 21/21 통과
- 속도 `1.0`에서 376블록 상승에 19.427초
- 임시 바닥 블록 4,606개 복구
- 탑승자 2명과 최상층 대기자 1명의 물리 상태 복구

층수는 고정되어 있지 않습니다. `minHeight`, `maxHeight`, 월드 건축 높이가 탐색 범위를 정합니다. 탐색 비용은 높이와 단면적에 비례합니다.

## 호환 방식

- Java 클래스 버전 52
- Spigot 1.13.2 컴파일 기준
- 오래된 서버에 없는 `World#getMinHeight` 같은 API만 리플렉션 사용
- 버전에 중립적인 재료와 효과음 탐색
- Bukkit, Paper, NMS 클래스 미포함
- `api-version: '1.13'`
- Folia 감지 시 안전하게 비활성화

## 남은 제한

- 실제 클라이언트 입력, 권한, 재접속, 화면 표시는 수동 확인이 필요합니다.
- Folia 리전 스케줄링은 구현하지 않았습니다.
- NoteBlockAPI `.nbs` 재생은 구현하지 않았습니다.
- 프로세스 강제 종료 시 임시 블록 복구를 보장할 수 없습니다.

운영 배포 전 [수동 인수 테스트](manual-acceptance.ko.md)를 진행하십시오.
