# 수동 인수 테스트

[English](manual-acceptance.md)

운영 서버와 같은 권한과 플러그인 구성을 가진 별도 서버 복사본에서 진행하십시오.

## 준비

1. Lift 또는 LiftReloaded JAR를 제거하고 SimpleLift만 설치합니다.
2. 기존 승강기와 설정을 테스트 월드에 복사합니다.
3. 서버를 정상적으로 시작하고 콘솔 오류를 확인합니다.
4. `/lift info`와 `/lift reload`를 실행합니다.

## 확인

- [ ] 빈 제어 표지판을 우클릭하면 모든 층 표지판이 초기화됩니다.
- [ ] 아이템 우클릭과 빈손 스크롤이 올바른 목적지를 순환합니다.
- [ ] 웅크린 스크롤은 `selection.fastStep`을 사용하고 손 바꾸기 키로 확정됩니다.
- [ ] 액션바에 선택 층, 층 이름, 현재 층이 표시됩니다.
- [ ] 시간 초과, 거리 이탈, 피해, 월드 이동, 리로드 시 선택이 종료됩니다.
- [ ] 두 사용자가 같은 표지판을 동시에 조작할 수 없습니다.
- [ ] 상승과 하강 후 중력, 비행, 무적, 충돌 상태가 복구됩니다.
- [ ] 보트, 광산 수레, 허용된 몹이 복제 없이 이동합니다.
- [ ] `lift`, `lift.change`, `lift.reload` 권한이 없으면 동작이 거절됩니다.
- [ ] 이동 중 로그아웃하거나 재접속해도 안전한 위치에 도착합니다.
- [ ] `preventEntry`와 `preventLeave`가 이동 중 진입과 이탈을 막습니다.
- [ ] 레드스톤 호출은 전원 변화마다 한 번만 시작됩니다.
- [ ] 양방향 운행 후 바닥, 레일, 표지판, 버튼이 복구됩니다.
- [ ] 같은 층의 여러 탑승자가 함께 도착합니다.
- [ ] 다른 층 호출은 `busy`를 받고 기존 운행 종료 후 동작합니다.
- [ ] 이동 경로 층의 사용자가 제자리에 남고 물리 상태를 유지합니다.

## 도착 알림음 (0.3.3)

- [ ] 버튼 재질과 태그 또는 기본값에 `hotel`을 지정하여 0·5·12틱의 낮은 하행 3음 알림과 재질별 지정의 우선순위를 확인합니다.

- [ ] warm과 clear가 각각 높은 음에서 낮은 음으로 내려가는 종소리 두 음을 8틱 간격으로 재생합니다. 같은 전체·클라이언트 음량에서 legacy와 비교하여 두 음이 왜곡 없이 명확하게 들리고 warm이 clear보다 낮게 들리는지 확인합니다.

- [ ] `language`를 en/de/ja/pt_BR/zh_TW/custom으로 바꾸고 재로드합니다. 조작 후 채팅·액션바·명령 응답·표지판 제목이 바뀌고 층 이름과 목적지가 유지되는지 확인합니다.

- [ ] 나무·돌 버튼의 도착음이 구분되고 미지정 재질은 `default`를 사용합니다.
- [ ] 재질별 지정이 태그보다 우선하며 `silent`, `soundEnabled: false`, 음량 0이면 무음입니다.
- [ ] 두 탑승자에게 각각 한 번 들리고 동시에 움직이는 다른 승강기는 각 호출 버튼의 음색을 유지합니다.
- [ ] 재질이 섞인 층과 레드스톤 호출도 목적지 버튼이 아닌 호출 버튼을 기준으로 합니다.
- [ ] 로그아웃·재로드 성공·종료 시 잔여 음이 취소되고 잘못된 재로드는 이전 설정을 유지합니다.
- [ ] 최저·최신 지원 클라이언트에서 음량, 왜곡, 음 사이 간격, 악기 누락을 청음합니다.

하나라도 실패하면 배포하지 마십시오. 실패 보고에는 설정, 서버와 Java 버전, 관련 로그, 승강기 화면을 포함하십시오.
