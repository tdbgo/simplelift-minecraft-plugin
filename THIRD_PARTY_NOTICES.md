# Third-party notices

SimpleLift includes code adapted from [LiftReloaded](https://github.com/kikelkik/LiftReloaded)
by kikelkik, the successor to [Lift](https://github.com/croxis/Lift) by croxis.
The implementation has been reworked and extended for SimpleLift.
SimpleLift is maintained separately by PLAYCITY BLOCK and is not an official
release of either upstream project.

## LiftReloaded

The adaptation is based on revision
[`5299b19aa85e8ff27cd729ac385b5ae83a53f08a`](https://github.com/kikelkik/LiftReloaded/tree/5299b19aa85e8ff27cd729ac385b5ae83a53f08a),
which includes a GNU General Public License version 3 license.

Adapted portions include elevator scanning and ride processing, floor removal
and restoration, passenger checks, scroll direction logic, legacy default
messages, and movement sound settings. SimpleLift changes the architecture,
state restoration, compatibility handling, floor selection, arrival chimes,
and language support.
